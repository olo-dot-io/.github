# OLo

**Grip, Speak, Done.**

We build voice-first software, connected hardware, and open-source tools for working with AI. OLo is based in the United States.

## What we build

- **OLo desktop** turns speech into text, app actions, and persistent AI agent workflows on macOS.
- **OLo hardware** brings a physical input to voice-driven work.
- **Uni-CLI** gives people and agents one command interface for APIs, browsers, desktops, local tools, and MCP.

## Open source

[**Uni-CLI**](https://github.com/olo-dot-io/Uni-CLI) — search, run, and inspect real software through a structured command interface.
